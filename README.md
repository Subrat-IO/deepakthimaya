# Deepak Thimaya — personal site

Next.js marketing / portfolio site for **Deepak Thimaya**.

**GitHub:** [`deepakthimaya`](https://github.com/Subrat-IO/deepakthimaya)

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Edit content under `app/` — the dev server hot-reloads.

## Stack

- Next.js (App Router)
- React, Tailwind / component library as configured in repo

## Build & deploy

```bash
npm run build
npm start
```

Deploy to Vercel or Hostinger Node/static hosting per project settings.
